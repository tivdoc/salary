# Parallel Development Wave 2 V0.4

Wave 2 extends the engineering foundation without authorizing a legal rule, numeric parameter, customer conclusion, source review, source activation, migration, deployment, or external service connection.

## Batch A

- The Wave 1 Git/evidence audit reconciles the registry, source pack, catalog observations, quarantine, ledgers, and change detections. The full-range scanner inventories every changed path, including tests, manifests, lockfiles, scripts, and executable configuration, and pairs static inspection with runtime denial canaries.
- Corpus hardening treats acquisition containers and operative instruments as separate evidence objects. Pension OCR is deterministic derived evidence only; it remains inactive and requires human page/line verification. Amendment relations and commencement/effectivity remain unverified candidates and are never auto-consolidated.
- Controlled import uses a forward-only local journal, fail-closed recovery and a bounded separate-process PDF screener. Persistent owner-import readiness remains empty. Local atomic rename is not a claim of directory-fsync, replicated custody, distributed locking, OS network namespaces, or complete native resource isolation.

All diagnostic readiness commands are separate from strict gates. Diagnostic commands may return exit zero with `not_ready`; strict commands return non-zero until every required gate is satisfied.
